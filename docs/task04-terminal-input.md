最终产品构建的完整终端运行 `500e28bbb42140e08b779873f578a4fc` 通过下列全部断言，被控端正常退出，临时诊断代码已移除。

## 实现与实际结果

手机将本地草稿显式发送为文本，Enter 独立执行；提供 Tab、四个方向键、Backspace 和 Ctrl+C。Windows 只在已授权的活动桌面会话中处理输入，文本和组合键均成对按下、释放；部分注入失败只释放本批次仍持有的键，并结束会话。过期键盘输入结束会话，防止丢失文本后继续执行 Enter。文件信令探针不开放输入权限。

验收使用原任务03手机（Android 16/API 36）、Windows 11 的普通交互桌面、PowerShell 5.1 与 PSReadLine 2.4.5；2560×1440 主显示器缩放为1280×720视频。终端使用独立临时目录和 Consolas 32 像素字体。测试前读到手机蜂窝数据开关为关闭；本任务未改动该设置，也未操作同时接入的另一台 Android 设备。

| 场景 | 独立外部断言 |
| --- | --- |
| 字符与 Enter | 0x20–0x7e 的全部95个可打印 ASCII 字符逐字一致；只发送文本时未执行，Enter 后真实 shell 输出与结果文件完全一致 |
| Tab | 补全真实目录中的唯一文件名，读取到 `TAB_COMPLETED` |
| Left、Right、Backspace | 编辑后实际结果为 `EDIT_ZYQ` |
| Up、Down | 选择并再次执行预期历史项，结果为 `HISTORY_A`、`HISTORY_B`、`HISTORY_B` |
| Ctrl+C | 原本存活的前台原生 PowerShell 子进程退出，未写入正常结束标记；随后能执行 `AFTER_CTRL_C` |
| 授权与结束 | 错误口令无首帧、无控制台变化；切后台后发送端正常退出；同一 Android 进程返回旧界面后输入无效，无 Java 崩溃 |
| 按键状态 | 每个场景后通过 Windows `GetAsyncKeyState` 检查鼠标、修饰键和本次功能键均已释放 |

结果来自实际文件、进程、Windows 控制台缓冲区以及手机截图；DataChannel 回显仅用于连通性检查。测试在发送前核对真实前台窗口，桌面失焦即停止，避免将测试命令输入其他窗口。

Agent 已查看原图和私有放大裁剪：后续编辑/历史截图显示 ASCII 输出、`TAB_COMPLETED`、`EDIT_ZYQ` 和预期历史序列；Ctrl+C 后可见 `FOREGROUND_RUNNING` 后恢复的终端提示符及后续命令。截图采集与视频反馈未同步，部分阶段截图早于其结果，Ctrl+C 恢复图尚未显示 `AFTER_CTRL_C` 输出行；精确内容和进程退出由独立 Windows 断言确认。软键盘打开时约334×188的桌面缩略图仅适合辨认布局，关闭后才能查看终端细节。旧会话画面变黑、控件灰显，但状态文字仍保留上次输入提示，任务05需统一结束状态呈现。

## 基线与修复证据

- 旧被控端与新增输入 UI 的对照运行 `e4057c8f9d8b4c0ab40613fdbfedecfe` 已配对、显示桌面并取得终端焦点，但发送文本和 Enter 后 Windows 缺少实际结果。初始实现通过同一行为断言，随后扩充全部字符和终端场景。
- 运行 `533e00f14f614d73ae4bd57fdf1dedd5` 的实际编辑结果为 `EDIT_ZQY`；最小重现确认 Right 按钮落入 Android 导航手势区域，触摸未到达按钮。系统栏/IME 边距修复后，运行 `038c90015deb438a9dcc84d7db3fd3a7` 得到正确的 `EDIT_ZYQ`。软键盘打开时保留草稿、发送按钮和缩小的桌面，关闭后恢复远端按键行。
- 运行 `74b8406192b04a1d8e29ea2be00c7034` 的系统日志显示 Wi-Fi 信号弱、系统断开 Wi-Fi 并销毁应用 TCP 连接，随后应用收到 SocketException。没有据此修改 TLS 协议或允许蜂窝回退；临时诊断代码已移除。最终回归中的 `03ad92b0ce4d48f9b9c5a1ffb203c638` 同样遇到 Wi-Fi 漫游：设备日志时间21:34:54.832 系统销毁原网络 TCP 连接，21:34:54.833 应用记录传输关闭。这些是失败证据，不计作功能通过或弱网性能验收。
- 带临时诊断的完整运行 `0991aa6ae03b45c197fb67d9e04a3fc8` 通过全部功能断言。移除诊断后重新构建两端并执行最终回归。首次干净构建运行 `d0fb21fb41734621abd07ec9073d04ce` 在 Tab 场景失败：会话未断，输入批次已注入，终端未产生第二条命令；截图中背景浏览器同时换页，疑似本地操作导致失焦，因此补充了每次发送前的前台窗口断言。
