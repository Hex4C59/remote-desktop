# 任务05：结束会话与手动重连

2026-09-27完成。审查基点为 `a2c0b51452f586347ec90f3d7f09f6125ce8eedf`，开始时工作区干净。沿用[规格](../.scratch/lan-remote-desktop-mvp/spec.md)、[任务03](task03-touch-pointer.md)和[任务04](task04-terminal-input.md)已确认的完整会话边界：华为 MatePad Pro 经卓易通运行 Android APK，通过正常地址和配对口令入口连接 Windows，观察实际桌面与专用终端。

## 实现

控制端增加“结束会话”和“重新连接”。后台、Wi-Fi 丢失、ICE 断开、输入通道关闭或信令结束都会禁用输入、清理 RTC/渲染资源并显示结束原因。迟到的输入发送结果与媒体状态不能覆盖结束提示。手动重连等待旧资源清理完成，再创建独立 Activity、线程、媒体连接和输入队列；保留电脑地址，重新输入配对口令，不继承旧草稿。不增加自动重连、后台服务或网络回退。

Windows 沿用任务02的一次性口令、单会话进程边界：结束后退出发送端，释放端口和控制占用；新会话需手动启动被控端取得新口令。测试通过正常启动程序和读取其配对窗口辅助这一人工流程，不复用旧授权。
