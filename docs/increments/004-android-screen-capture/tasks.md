# Android 被控端画面采集任务清单

## 依据

以 [采集规格](spec.md) 和 [技术方案](plan.md) 为依据。规格获批、平台和线程约定同步后开始实现。按波次执行，每波先确认新增行为的红灯，再实现并运行该波覆盖的用例。红绿灯记录和实测统计归入 `test-results/android-capture/`，格式见 [测试与验收](../../verification/README.md)。

## 波次 1 · 构建与测试准备

- [ ] T001 核对并固定 JDK、SDK、AGP、Gradle Wrapper 和测试依赖版本，定义自动化测试与 APK 的构建命令。（路径 `src/platform/android/`。验证最小工程能构建，测试入口能发现并运行基线用例。）
- [ ] T002 声明规格中的控制接口和状态类型，准备授权、平台调用、采集资源及图像缓冲的测试替身。（路径 `src/platform/android/`。验证测试源能编译，替身可观察调用次序和释放次数。）

## 波次 2 · 授权与生命周期

- [ ] T003 写 `AC-01`～`AC-03`、`AC-06`～`AC-07` 的自动化用例。（路径 `src/platform/android/` 的测试源集。断言拒绝后的状态及调用次数、启动顺序、不同失败点的释放次数，以及停止后的状态和统计。）
- [ ] T004 实现授权结果的代次校验、前台服务与投影启动、回调分派与串行清理。（路径 `src/platform/android/`。重跑 T003 的用例，确认原断言通过。）

## 波次 3 · 首帧与尺寸变化

- [ ] T005 写 `AC-04`、`AC-05` 和 `AC-08` 的自动化用例。（路径 `src/platform/android/` 的测试源集。验证带行尾填充的像素、空帧与坏帧处理、终止原因及虚拟显示创建次数。）
- [ ] T006 接入 `VirtualDisplay` 和 `ImageReader`，实现像素验证、首帧统计及尺寸变化终止。（路径 `src/platform/android/`。重跑 T003、T005，核对停止和失败路径均回收图像与投影资源。）

## 最终波次 · 验收与证据

- [ ] T007 构建并安装候选 APK，在 Android 14+ ARM64 真机执行 `ACH-01`～`ACH-04`。（路径 `src/platform/android/`。证据写入 `test-results/android-capture/`，记录设备、版本、像素检查结果、首帧耗时、帧数和回调耗时。）
- [ ] T008 执行规格校验、C++ 全量回归及 Android 自动化测试，按验收编号汇总命令、用例结果和证据路径。（路径 `test-results/android-capture/`。验证所有验收条目都有结果记录。）
