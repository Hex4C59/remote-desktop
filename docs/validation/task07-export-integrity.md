## 实现与成功条件

导出保持64 KiB缓冲，按以下顺序执行：完成全部ZIP内容与目录；刷新输出并同步文件描述符；关闭目标；通过独立读取将文件暂存到应用缓存；按ZIP中央目录遍历所有项，逐项核对CRC与未压缩长度；比较写入与回读的字节数及全文件SHA-256。全部通过后才显示导出成功及回执。ZIP关闭使用只刷新、不关闭调用者文件的包装，确保同步发生在有效文件描述符上，并保持批量写入。

新增“校验已导出 ZIP”只读入口，使用系统文件选择器检查历史导出包，不修改原文件。ZIP结构/CRC失败与读取/缓存失败分别提示；任何失败保留原始实验及目标文件。校验只在独立后台线程运行，复用既有导出互斥与Activity观察机制。暂存文件在成功和失败路径均清理，磁盘需求约为一份导出包大小；流缓冲为64 KiB量级。无法同步的文件提供者会报告失败，不降低成功条件。

平板内校验不能证明MTP读到相同内容。回收完成并关闭文件后，还必须核对平板回执。公开离线入口如下，`BYTES`与`SHA256`取自平板完成提示：

```sh
python3 scripts/latency/archive.py recovered.zip --bytes BYTES --sha256 SHA256
```

命令只读检查回执及全部ZIP CRC，不解包、不删除失败副本。通过后仍须执行单实验/会话索引和全部I420帧解压校验，再生成复核页。CRC或哈希通过不表示人工确认了反馈边界。
